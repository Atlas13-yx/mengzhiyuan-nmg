# 蒙志愿

面向内蒙古考生的高考志愿智能决策平台。首版重点解决 2026 新高考下的院校专业组比较、特殊类型招生分流、官方公告整理和自然语言筛选。

## 当前可用功能

- 首页报考工作台：院校搜索、个人档案、官方入口、数据快照与下一步操作
- 公告中心：分类、搜索、分页、时间线与月历；日程逐项保留官方来源
- 特殊招生：军校、公安、司法、艺术、体育、中外合作、港校七条资格路径及核对清单
- 自然语言筛选：文字或浏览器语音输入 → 本地规则解析 → 可编辑条件 → 确认初筛；尚未接入 AI 模型服务
- 官方计划库：1,663 个院校招生单元、9,300 个专业组/招生单元、27,553 条专业计划；2025 历史分数按来源和轮次保留
- 志愿草稿：从真实专业组加入、排序、恢复、对比、选科初筛、CSV 导出和打印
- 公告抓取：默认每年 6 月 10 日至 8 月 31 日每小时运行，活动窗口可配置，失败保留最近成功缓存
- 官方直达：首页固定提供“平安高考”入口，保留原文来源链路

> 当前是 2026 年资料版，计划快照与历史分数不是实时录取结果。尚缺往年完整组内计划，不能只凭相同组号推断专业构成、扩缩招或冲稳保；页面不会为真实专业组生成虚假录取概率。地域、院校性质和专业偏好暂只作人工核验条件。

公开站点：https://atlas13-yx.github.io/mengzhiyuan-nmg/

## 本地开发

```bash
npm install
npm run dev
```

访问 `http://localhost:3000`。

Windows 用户也可以运行 `npm run preview`，脚本会完成构建并检查 `http://127.0.0.1:4173` 的页面与静态资源。

验证命令：`npm test`（应用类型检查、生产构建、全部 Node 回归测试）。GitHub Pages 从源码使用 Next 静态导出至 `out/`；仓库中保留的旧 `site/` 仅是历史产物，不再作为发布输入。Cloudflare worker/database 是独立部署目标，不纳入纯前端类型配置。

## 公告同步

```bash
npm run sync:notices
```

GitHub Actions 每小时第 17 分钟检查，窗口外退出而不抓取；调度可能受 GitHub 队列延迟。仓库变量 `SYNC_START_DATE`、`SYNC_END_DATE` 接受 YYYY-MM-DD，按北京时间包含首尾日期。每届需按官方完整录取安排调整窗口；默认日期不是官方截止日期。手动补抓可选 workflow 的 force，或设置 `FORCE_SYNC=1`。

成功更新会显式触发 Pages 发布；页面展示真实采集时间和公告日期依据。当前时间线只整理五个已核对的 2026 重要节点，不冒充完整日历，不复用于下一届。

## 数据建设路线

1. **官方招生计划标准化**
   - 年份、批次、科类、院校、院校专业组、组内专业、计划数
   - 选科、外语、单科、体检、性别、专项资格、蒙古语文等限报条件
2. **跨年专业组对齐**
   - 不能只按组号匹配；以“院校 + 选科要求 + 专业集合相似度”建立稳定组实体
   - 保留拆组、并组、专业迁移和计划增减事件
3. **录取数据**
   - 优先自治区教育考试院批量投档/录取最高最低分
   - 其次高校官网分省录取数据；第三方信息只作补充并标记可信等级
4. **特殊招生资格引擎**
   - 军事、公安、司法、消防、北京电子科技学院、定向军士等意向志愿与资格链
   - 艺术体育综合分、统考方向、校考和双上线
   - 中外合作学费与培养地点、港校统招/独立招生分流
5. **推荐模型**
   - 风险单位始终是院校专业组，不用院校最低分替代
   - 输出命中依据、数据年份、变化原因和退档风险，不给“保证录取”结论

## 数据来源原则

- [内蒙古招生考试信息网](https://www.nm.zsks.cn/)
- [平安高考专题](https://www.nm.zsks.cn/ztzl/pagkpt/)
- [阳光高考](https://gaokao.chsi.com.cn/)
- 高校本科招生官网

正式填报必须回到自治区官方系统。本项目只做辅助决策，不收集考生号、密码等敏感信息。档案和志愿草稿仅保存在当前浏览器，不具备账号同步；请导出备份。浏览器语音识别可能使用其提供商在线服务，点击语音按钮后才请求麦克风权限。
