# 蒙志愿

面向内蒙古考生的高考志愿智能决策平台。首版重点解决 2026 新高考下的院校专业组比较、特殊类型招生分流、官方公告整理和自然语言筛选。

## 当前可用功能

- 首页决策总览：分数、位次、选科与冲稳保方案入口
- 官方日程：模拟演练、意向类别、批次投档与征集志愿时间轴
- 特殊招生：军校、公安司法、艺术体育、中外合作、港校单独入口
- AI 需求输入：支持中文语音识别与文字输入，提取地域、专业、预算等条件
- 院校专业组工作台：以组为风险单位，展示专业构成、计划变化和偏好匹配
- 公告抓取：每年 6 月 7 日至 8 月 20 日每小时同步“平安高考”栏目
- 官方直达：首页固定提供“平安高考”入口，保留原文来源链路

> 当前院校专业组推荐区为产品演示数据，页面已显著标注。正式使用前必须接入并校验当年官方招生计划、院校章程、资格名单和录取数据。

## 本地开发

```bash
npm install
npm run dev
```

访问 `http://localhost:3000`。

## 公告同步

```bash
npm run sync:notices
```

GitHub Actions 在活动窗口内每小时第 17 分钟执行一次；窗口外主动退出。手动测试可临时设置 `FORCE_SYNC=1`。

## 数据建设路线

1. **官方招生计划标准化**
   - 年份、批次、科类、院校、院校专业组、组内专业、计划数
   - 选科、外语、单科、体检、性别、专项资格、蒙古语文等限报条件
2. **跨年专业组对齐**
   - 不能只按组号匹配；以“院校 + 选科要求 + 专业集合相似度”建立稳定组实体
   - 保留拆组、并组、专业迁移和计划增减事件
3. **录取数据**
   - 优先自治区教育考试院批量投档/录取最高最低分
   - 其次高校官网分省录取数据；第三方信息只作补充并标记可信等级
4. **特殊招生资格引擎**
   - 军事、公安、司法、消防、北京电子科技学院、定向军士等意向志愿与资格链
   - 艺术体育综合分、统考方向、校考和双上线
   - 中外合作学费与培养地点、港校统招/独立招生分流
5. **推荐模型**
   - 风险单位始终是院校专业组，不用院校最低分替代
   - 输出命中依据、数据年份、变化原因和退档风险，不给“保证录取”结论

## 数据来源原则

- [内蒙古招生考试信息网](https://www.nm.zsks.cn/)
- [平安高考专题](https://www.nm.zsks.cn/ztzl/pagkpt/)
- [阳光高考](https://gaokao.chsi.com.cn/)
- 高校本科招生官网

正式填报必须回到自治区官方系统。本项目只做辅助决策，不收集考生号、密码等敏感信息。
