# 蒙志愿 · 设计完善记录

## 主流程

首页查校 → 官方招生计划 → 逐专业组核对 → 加入本地草稿 → 两组比较/资格自查 → 排序导出 → 跳转官方填报。

智能入口是另一条查校路径：说出或输入需求 → 展示解析草稿 → 用户修改确认 → 院校目录初筛。当前为规则解析，不把未接入的模型称为真实 AI 推理。

## 界面细节

- 首页改为工作台，优先提供查校、档案、公告和官方服务，而不是大幅宣传图。
- 七个主导航在窄屏横向滚动；表格使用局部滚动，避免整个页面横向溢出。
- 首次访问不把默认示例分数当作用户已保存档案。
- 每个专业组保留年份、院校/组代号、批次、科类、计划类别、专业、费用和官方来源。
- 收藏恢复时重新核对计划快照；离线、已失效、未建档、选科不符与特殊资格待核验分别提示。
- 空结果、加载失败、语音不支持和本地存储不可用均有可继续操作的提示。
- 清空志愿需要确认；导出 CSV 对电子表格公式做转义。

## 数据边界

- 当前计划年份为 2026，已整理 2025 历史分数。缺失值显示缺失，不填入零或推算数。
- 历年同组号仅是候选关联；批次、科类、计划类别也必须一致。缺少往年组内专业计划时不计算年度增减。
- 军校、公安、司法、艺术、体育、中外合作和港校分开指引，不共用普通类录取门槛。
- 当下公告是历史归档；默认采集窗口必须随每届官方进程维护。自动采集公告索引，时间线节点需核对原文后整理。
- 语音识别取决于浏览器支持；院校地域/性质等属性未形成核验库前，不冒称这些偏好已影响筛选结果。
- 草稿不是考试院志愿表，不自动提交、不承诺录取、不索取考生账号密码。

## 后续优先级

1. 补齐往年官方组内计划，建立有人工审核的拆组、并组与专业迁移关系。
2. 补充院校属性、章程条件及港校独立招生数据。
3. 增加服务端 AI 结构化解析，保留用户确认环节，密钥只存服务端。
4. 引入可选账号同步与备份，在收集任何个人信息前明确告知并征得同意。
